# Miles & Meals v61 — Planner → Expense + Global Trip Search

## Planner → Expense

Every planner item now includes **Add expense**.

The expense form is opened with useful fields prefilled:

- trip/destination
- date
- description
- category suggestion based on planner type/title

The user still confirms amount, payer and split before saving.

## Search

New `/search` page searches across all trips the user can access:

- expenses
- planner items
- shared activity

Search is available from **More → Search trips**.

No database migration is required.
