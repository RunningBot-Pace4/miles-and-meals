# Miles & Meals v65.1 — Build Hotfix

Fixes the strict TypeScript build error in `ExpenseForm.tsx` caused by an invalid type predicate while locating a form control inside a `RadioNodeList`.

Before:

```ts
(item): item is HTMLElement => item instanceof HTMLElement
```

After:

```ts
(item) => item instanceof HTMLElement
```

`RadioNodeList` items are typed as `HTMLInputElement`; the old predicate incorrectly tried to narrow them to the broader `HTMLElement` type, which TypeScript rejects. The new code lets TypeScript infer the valid subtype and still assigns the resulting input to the `HTMLElement | null` target.

No database migration is required.
