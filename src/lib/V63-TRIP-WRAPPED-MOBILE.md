# Miles & Meals v63 — Trip Wrapped + Mobile Expense Polish

## Mobile Add Expense redesign

The mobile expense form is tightened for real phone use:

- more compact section spacing
- cleaner rounded mobile controls
- 4-column category selector on common phone widths
- short currency-code dropdown with readable currency helper text
- improved amount/currency composition
- extra bottom space so fixed navigation does not crowd the form
- sticky save position tuned above the mobile navigation

## Trip Wrapped

New `/wrapped` post-trip snapshot includes:

- total group spend
- personal share
- top category
- biggest spend
- traveler count
- meals logged
- planner count/progress
- completed settlements
- average spend/day when trip dates are available

Trip Wrapped is available from **More** and supports choosing any accessible trip.

## Consolidated release

v59, v60, v61, v62 and v63 are packaged together in this source release.
No database migration is required from v58.
