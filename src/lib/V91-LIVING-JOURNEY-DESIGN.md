# V91 Living Journey design system

The Halo connects the app's four working systems:

| Mode | Purpose | Main destinations |
| --- | --- | --- |
| Move | What is next, route, tickets and offline travel essentials | Map and Documents |
| Plan | Today's rhythm, itinerary, tasks and packing | Plan and Trip Companion |
| Spend | Personal share, allowance, forecast and settlement | Add Expense and Settlement |
| People | Travelers, updates, shared location and confirmations | Map and Notifications |

The centre answers one question: **What matters now?** Each Halo choice changes the live summary, metrics and primary actions without hiding the full Home data below it.

The product keeps serious finance screens clear while using deeper colour, motion and the four-part journey identity to create more travel emotion. Motion is restrained and disabled when the device requests reduced motion.

V91 is a presentation and interaction release. It does not change V90 calculations, permissions, closed-Trip locks, offline data rules or the database schema.
