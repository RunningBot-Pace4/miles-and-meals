# Miles & Meals v59 — Home Action Centre + Activity Timeline

## Home becomes the command centre

The existing Home dashboard now surfaces useful actions before the user has to hunt through modules.

Examples:

- unread notifications
- money the current user still needs to settle
- sent payments waiting for the current user's received confirmation

The section only appears when there is something actionable.

## Recent activity on Home

Home now shows the latest shared trip activity with actor and Malaysia-local timestamp.
The existing full `/activity` page remains available through **View all**.

## Privacy

Activity remains restricted to trips/countries the current user can access.

No database migration is required.
