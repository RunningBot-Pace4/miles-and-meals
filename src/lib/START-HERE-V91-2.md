# Start here — V91.2 Living Journey Home

Miles & Meals `1.91.2` replaces the oversized no-Trip hero and ordinary empty card with the actual interactive Living Journey experience.

## What users see

- Before the first Trip: an interactive Move, Plan, Spend and People Halo that explains the product and leads directly to Trip creation.
- With an active Trip: the Halo switches to live itinerary, route, budget, balance, settlement, traveller and notification data.
- On PC: a balanced Halo and live-information panel rather than an oversized empty banner.
- On an installed PWA: the same experience collapses cleanly from 430px down to 320px.

## Deployment

1. No Neon script is required for V91.2.
2. Deploy the complete V91.2 source package to Vercel.
3. Open the app online once so the `miles-meals-static-v91-2` service worker activates.
4. Hard-refresh any existing browser tab.

The V85 and V90 migrations must already be present from their original releases.
